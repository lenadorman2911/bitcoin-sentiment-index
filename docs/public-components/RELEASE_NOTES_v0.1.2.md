# Proposed v0.1.2 release notes

This add-on shares three frozen study sources: Wikimedia pageviews, the corrected Google Trends component with individual query observations, and Alternative.me CFGI. Source-specific conditions and attribution are recorded separately from the MIT code license.

An offline checker reconstructs the Google common-anchor ratio, checks rolling normalization against frozen references and verifies file fingerprints. The full combined input is not included. No core analysis code, numerical study result or previous release is replaced by this add-on.
