# Data access and distribution

Code and input data have separate release decisions. MIT applies to the original project code, not to third-party observations.

The public release contains no analysis input, raw Reddit text, provider export or request cache. A SHA-256 identifies the required frozen input. A separate local archive can preserve that input for the owner without asserting a right to publish or transfer it.

## Review recorded on 24 October 2026

| Source | What was checked | Release decision |
| --- | --- | --- |
| Alternative.me | Published API rules require attribution and prohibit impersonation; commercial use is allowed with attribution beside the display | Retain source attribution. These rules are not a license for the entire combined dataset. |
| Reddit | Data API terms distinguish access rights from ownership and permitted uses of user content | No raw content is distributed. These API terms alone do not settle permission to redistribute derived aggregates obtained through a third-party archive. |
| Google Trends | Official data documentation describes sampled, normalized and aggregated search statistics | This documentation does not establish a blanket redistribution license for the combined frozen input. |
| Other market, derivatives, stablecoin, pageview and development sources | Full redistribution review has not been completed | Do not publish the combined input until the applicable source terms and any required permissions are recorded. |

Sources:

- Alternative.me API rules: https://alternative.me/crypto/fear-and-greed-index/#api
- Reddit Data API Terms: https://redditinc.com/policies/data-api-terms
- Google Trends data documentation: https://support.google.com/trends/answer/4365533?hl=en

The private archive is for local preservation, not a public data release. Private sharing is not automatically authorized merely because a repository is private. Obtain an appropriate basis before transferring data to reviewers or other recipients. A controlled-access statement should describe the actual access process only after it has been arranged; this version does not promise access on request.
